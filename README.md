# EpiPrint — тестовый кабинет (прототип портала)

Рабочий прототип портала по ТЗ (`../ТЗ_портал_онко_метилирование_v0.1.md`).
Многостраничный HTML на демо-данных — для наглядности при обсуждении с коллегами.
Живого бэкенда, пайплайна и реальных данных здесь нет; всё это заглушки.

## Как открыть

**Просто дважды кликни `index.html`** — откроется в браузере. Всё работает офлайн,
данные зашиты в файлах, никакой установки не нужно. Дальше кликай по разделам в меню слева.

> Мелочь: шрифты (Montserrat/Inter) подгружаются из интернета. Без сети портал
> откроется и будет работать — просто шрифт будет системный. С интернетом — как на скриншотах.

## Что внутри (8 страниц)

| Файл | Раздел | Что показывает |
|---|---|---|
| `index.html` | Главная | Дашборд + **мониторинг монтирований** (статус хранилище→зеркало→веб) |
| `storage.html` | Хранилище | Прогоны и образцы; **пакетный запуск** «выбрал → запустить всё» |
| `queue.html` | Очередь | Стадии пайплайна, логи, статусы + **автообновление** (без ручного «Обновить») |
| `samples.html` | Образцы | Реестр с поиском и фильтрами (статус, набор, риск) |
| `sample.html` | Карточка образца | Гейдж вероятности, локализация, **хитмап**, QC (Pass/Fail), **обратная связь для дообучения** |
| `qc.html` | Контроль качества | Сводка QC-метрик по всему потоку |
| `compare.html` | Сравнение наборов | Один образец на Vazyme / Rasel / Burning Rock рядом |
| `report.html` | Заключение | Лабораторный отчёт в стиле НИПТ/Galleri, печать/PDF (`Cmd+P`) |

`assets/` — общий слой: `style.css` (дизайн), `data.js` (мок-данные), `app.js` (логика/компоненты).

## Что «живое» в прототипе

- Навигация между страницами, поиск и фильтры по образцам.
- Пакетный запуск на «Хранилище» (образцы уходят в статус «в очереди»).
- Автообновление очереди: активный образец «проходит» стадии пайплайна на глазах.
- Обратная связь на карточке: выбор «подтверждён / не подтверждён» **сохраняется** (в браузере, localStorage).
- Печать заключения в PDF.

Кнопки скачивания (TSV/JSON/логи) и e-mail показывают уведомление-заглушку — реальных файлов нет.

## Мок-данные

24 образца генерируются детерминированно (`assets/data.js`) — цифры выглядят
правдоподобно и не «прыгают». Ничего из этого не является реальными медицинскими данными.
Хочешь поправить наборы, пороги QC, число образцов, виды рака — всё в `data.js`.

## Если захочется выложить ссылкой (GitHub Pages)

Чтобы отправить коллегам ссылку, а не папку:

1. Создать репозиторий на GitHub, положить туда содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/root` → Save.
3. Через минуту портал будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Никакого билд-шага не нужно — это статические файлы. GitHub Actions понадобится только
если позже захотим автосборку/автопубликацию; для текущего прототипа достаточно Pages.
